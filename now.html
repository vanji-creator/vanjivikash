What I'm actually doing this month

Dated, so you can tell how stale it is. If the date is old, so is the page.

Building

Answer generation for Kural RAG. The retrieval half is finished and scored; the generation half is wired end to end with every citation checked against the verses the model was actually handed, but it has not been attacked yet — no adversarial pass, no deliberate feeding of wrong verses, no hunt for invented citations at scale. Until that runs it is not going in front of anyone.

The honest description, and the one used everywhere on this site: citation-checked, but not yet adversarially tested.

Behind that, the reranker needs to be quantized so it can serve from a CPU. The rule I set before starting is that it ships only if it answers all 233 benchmark questions identically — speed bought at the cost of accuracy is not a trade this project makes.

Stuck on

Calibration. Kural RAG's scores cannot yet separate a question the book answers from one it does not — 14 of 15 deliberately off-topic questions score exactly 0.000, but so does at least one genuine question. A refusal floor set anywhere useful would turn away four real questions to catch one fake, which is a worse trade than refusing nothing.

calibrated: false

Travels all the way to the browser. The interface refuses to claim confidence rather than inventing a threshold the measurement does not support.

The other open one is measuring citation validity. It needs a judge, and the three judges I compared on 113 claims disagreed too much to trust — one of them called a word-for-word quote unsupported. Finishing the human worksheet is the unglamorous fix, and it is the next thing after the breaking tests.

Next

  1. Adversarial tests against the generator, before anybody sees it.
  2. Quantize the reranker, at proven-zero accuracy cost or not at all.
  3. Host it — the target is under ₹700 a month, with a spending cap and per-IP rate limiting.
  4. Grow the test set. The golden set is at 97 of 100, so it can no longer tell a real improvement from none. The ruler needs to grow, not the model.
  5. Write the three pieces listed on the home page.
